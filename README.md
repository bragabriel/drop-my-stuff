# DropMyStuff

Site vitrine para divulgar itens pessoais à venda (eletrônicos, móveis e mais), com o contato de compra levando para Instagram/WhatsApp.

## Stack

- [React](https://react.dev/) 19
- [Vite](https://vite.dev/)
- TypeScript

## Como rodar

```bash
# Instalar dependências
npm install

# Ambiente de desenvolvimento
npm run dev

# Build de produção
npm run build
```
